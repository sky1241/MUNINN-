# CHUNK C1 (2026-05-08): pin optional dependencies for reproducible builds.
#
# Pre-fix: pyproject.toml used `tiktoken>=0.5`, `anthropic>=0.20` — any
# `pip install -e .[all]` could pick up a 2-year-old version OR a
# brand-new breaking release. Builds were not reproducible across
# environments / CI / fresh machines.
#
# Strategy: pin the currently-tested versions here as upper bounds.
# Use via:  pip install -c constraints.txt -e '.[all]'
# Or in CI: pip install -c constraints.txt -r requirements-dev.txt
#
# Update procedure: bump the pin, re-run `pytest tests/`, commit the
# new pin only if all tests pass. Dependabot (CHUNK C13) will open
# PRs that propose bumps.
#
# Source: docs/CHUNKS_AUDIT2_FIX_LIST_2026-05-08.md §C1

# Optional LLM compression (L9) — bumped to 0.100.0 (2026-05-09 v3 audit;
# 0.97 = CMA Memory beta, 0.95 = Bedrock auth breaking change).
anthropic==0.100.0

# Crypto (vault.py AES-256-GCM, sync_tls). 46.0.7 patches CVE-2026-39892;
# 48.0.0 = currently tested in dev (2026-05-09 audit v3).
cryptography==48.0.0
