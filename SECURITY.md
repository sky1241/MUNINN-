# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in MUNINN, please **do not open a public
issue**. Instead, report it privately by emailing the maintainer or by using
GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
feature (Security tab → "Report a vulnerability").

Include:
- **Description** of the vulnerability and its impact
- **Steps to reproduce** (proof of concept if possible)
- **Affected version(s)** and component (engine/core/, hooks, sync, MCP, …)
- **Suggested fix** if you have one

## Response Timeline

| Stage          | Target  |
|----------------|---------|
| Acknowledgment | 72h     |
| Triage + fix plan | 7 days |
| Patch released | 30 days for CRIT, 90 days for others |

## Scope

In-scope:
- MUNINN engine (engine/core/, muninn/) and CLI
- Hook scripts (.claude/hooks/) generated by `muninn install`
- Sync protocol (sync_tls.py, mTLS handshake, audit log)
- Vault encryption (vault.py — AES-256-GCM)
- MCP server stdio interface

Out-of-scope:
- Third-party dependencies — report upstream (see `constraints.txt` for pinned versions)
- Claude Code itself — report to Anthropic
- User-supplied prompts and their downstream effects

## Hardening already in place

- **Secrets pre-injection scrubbing**: 29 regex patterns in `engine/core/_secrets.py`
  redact API keys, tokens, private keys before any text enters the mycelium.
- **Hook integrity**: `.claude/hooks/hooks.sha256sum` manifest, verified by
  `test_chunk_a7_hook_integrity.py`. Hooks chmod 0o700.
- **Vault**: AES-256-GCM (`cryptography` 48.0.0+, patched against
  CVE-2026-39892 in 46.0.7+).
- **Sync over TLS**: mutual TLS for cross-PC sync (`sync_tls.py`).
- **CI hardening**: `permissions: { contents: read }` (CHUNK C12).
- **Dependency pinning**: `constraints.txt` pins 8 critical deps. Dependabot
  weekly scan.

## Disclosure Policy

We follow [coordinated disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure).
Once a patch is released we credit reporters in the release notes unless
anonymity is requested.
